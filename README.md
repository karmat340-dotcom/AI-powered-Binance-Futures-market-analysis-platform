# TRADE AI — Binance Futures Market Analysis

A desktop-first, responsive React dashboard for live Binance USDⓈ-M Futures market data.

## Run on your PC

1. Install Node.js (LTS).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local address printed by Vite (usually http://localhost:5173).

## Current prototype features

- Live public Binance Futures ticker and candlestick REST data.
- Symbol watchlist and Binance timeframe selector.
- EMA 9/21/50 and RSI(14) calculations.
- Basic LONG/SHORT/WAIT technical confluence label.
- Desktop-first layout with responsive mobile styling.

## Important

The current signal is a basic technical-rules prototype, not a trained AI model or a guaranteed trading signal. Entry/stop/target levels are not yet generated. No orders are placed and no API keys are required. Test with paper trading before risking funds.
